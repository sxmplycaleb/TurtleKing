# Turtle King Sound Assets

All audio in this directory is **original work generated by this repository**
via `tool/generate_sounds.dart` — synthesized from basic waveforms (sine and
sawtooth tones, noise bursts, decay envelopes) plus additive harmonic voice
synthesis with formant shaping for the two YAMADA voice clips (M17.3). No
third-party audio, samples, speech, or recordings are used, so there are no
external licensing or attribution requirements.

**License:** project-owned (same license as the rest of the Turtle King code).
Feel free to regenerate or modify any sound by editing the generator and
re-running `dart run tool/generate_sounds.dart` (seeded — output is
byte-reproducible).

## Format

16-bit PCM, mono, 22050 Hz — universally supported by the `audioplayers`
playback backend (media3/ExoPlayer on Android, AVAudioPlayer on iOS). Total
on-disk size: ~180 KB for all eight files. All sounds are distinct in content
and duration (unique hashes/sample counts, tested); the set is
byte-reproducible from the seeded generator.

## M17.3 final polish — audio audit

Every bundled sound was measured (duration, RMS/loudness, peak/clipping,
leading/trailing silence, sample rate, size) and checked against its intended
character. Results: no sound has any leading silence (no measured latency
contribution), all peaks are now below full scale (no clipping), every tail
fades to silence, and all eight durations remain mutually distinct. The
`hold_out.wav` approved asset is byte-for-byte identical (SHA-256 pinned in
`test/audio_assets_test.dart`); `handoff.wav` was left as-is. See the README
M17.3 section for the finding-by-finding table.

## M17.4 — intelligibility & reveal redesign

The two YAMADA voice clips were redesigned around explicit phoneme segments
(`YAH` → `mah` → `DAH!!!`, with a stop-consonant closure gap before the
`/d/`) so they are clearly intelligible as "Yah-mah-DAH!!!" rather than
three blurred syllables; the deep voice's formants and sub-octave were
rebalanced so it no longer sinks into the low end, and the anime voice's
breath was reduced so it stays bright without being harsh. `reveal.wav` was
replaced with a quick G6→A6→C7 bell sparkle landing on a bright "ding"
(0.36 s). All changes came from the seeded, byte-reproducible generator and
remain project-owned; `hold_out.wav` is byte-for-byte unchanged (SHA-256
`5db1bd…c7829bad`). See the README M17.4 section for the phoneme table and
full audit.
