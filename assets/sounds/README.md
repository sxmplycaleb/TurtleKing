# Turtle King Sound Assets

All audio in this directory is **original work generated by this repository**
via `tool/generate_sounds.dart` — synthesized from basic waveforms (sine and
sawtooth tones, noise bursts, decay envelopes). No third-party audio, samples,
or recordings are used, so there are no external licensing or attribution
requirements.

**License:** project-owned (same license as the rest of the Turtle King code).
Feel free to regenerate or modify any sound by editing the generator and
re-running `dart run tool/generate_sounds.dart` (seeded — output is
byte-reproducible).

## Format

16-bit PCM, mono, 22050 Hz — universally supported by the `audioplayers`
playback backend (media3/ExoPlayer on Android, AVAudioPlayer on iOS). Total
on-disk size: ~115 KB for all seven files.
